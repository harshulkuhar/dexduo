# Embedded rear camera

Scan starts a rear-camera preview inside the green LCD on iPhone and Duo. The preview uses aspect fit: the entire frame remains visible, with green unused space. Capture freezes one photograph and runs the existing local recognition pipeline. Retake clears the image, candidates and failed-lookup state, then resumes the camera. No continuous inference, OCR, new thresholds or automatic Photos saves are introduced.

Import pauses capture. Cancelling restores the preceding live preview or frozen result; selecting an image uses the existing import/recognition path. Candidates and lookup Retry remain intact. Done stays fixed. Accessibility sizes expose Preview/Results pages with capture and import controls available on either page. Permission denial offers Settings and Import; Simulator offers Import with the camera-unavailable explanation.

`CameraCapture.swift` owns the serial AVFoundation session, photo delegates, generation-guarded controller and aspect-fit preview layer. Apple’s [rotation coordinator](https://developer.apple.com/documentation/avfoundation/avcapturedevice/rotationcoordinator) supplies separate preview and photograph angles. `Scanner.swift` owns picker presentation, Retake, inference and application lifecycle cancellation. Phone and Duo reuse the same preview and controls. Backgrounding, closing, folding and interruptions stop capture and reject obsolete results. Foregrounding resumes a previously live preview; captured/imported results remain frozen.

Acceptance covers permission denial/unavailability, capture/Retake, duplicate capture protection, cancelled imports, stale authorization/photo/interruption callbacks, background resume, failed lookup Retry, reachable controls at accessibility sizes, both phone landscapes and existing Duo orientation. Native captures, framing, EXIF orientation and actual card/screen recognition must also be checked on an iPhone. Simulator and mocked camera tests do not establish physical-camera correctness. Actual Duo camera checks require hardware. Evidence remains outside Git.
